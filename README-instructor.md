# Teacher Notes (Plain HTML/CSS Starter)

## What students should submit
- A zip of the exported site folder, OR
- A shared folder link, OR
- A published URL (optional)

## Quick check
1. Unzip.
2. Open `index.html` in Chrome.
3. Click Home/About/Sources.
4. Confirm content is filled in and Sources has real citations.

## Common issues
- Broken links: filename mismatch (capitalization matters)
- Missing CSS: `css/styles.css` moved or renamed
